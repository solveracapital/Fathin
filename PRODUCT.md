# Multivariat Lab

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated and accepted: React TypeScript Vite frontend; Python FastAPI backend with statsmodels EFA (no R runtime). Local-first browser application.

## Users and purpose
Students learning multivariate analysis and presenting to lecturers. Users upload numerical tables, choose an analytical question, inspect reproducible calculations and assumptions, and present actual results. User has approved briefs/FRONTEND.md and briefs/BACKEND.md and authorized implementation without another direction workshop.

## Capabilities and boundaries
LDA binary, PCA, EFA, k-means, hierarchical clustering. Taiwan paper example is LDA with separate PCA illustration; EFA/clustering are additional explorations. AI is optional; numerical results come from statistical engine. No claims of actuarial deployment validity.

## Evidence and design authority
briefs/ contains the approved product, API and frontend direction. Teal restrained light workspace, Source Sans 3, no decorative dashboard content. Operate mode, with reading and presentation surfaces. Fonts and charts must work locally. No new aesthetic selection is needed.
